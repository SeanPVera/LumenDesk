# LumenDesk — Spectrum Studio

LumenDesk is a precise creative workspace for enthusiasts shaping the light in
a room. Spectrum Studio combines a room-wide view with deep control of each
fixture. The Mac app is the lead experience.

## Visual thesis

Graphite surfaces hold actual fixture color; warm amber marks studio actions and
fader travel. Device lanes make the installation readable at a glance. Opening a
light pairs its physical geometry with exact color and intensity values, so a
composition can be judged visually and adjusted numerically in the same place.

Use reported topology for Nanoleaf, model-specific regions for Govee, and Luna's
26 active zones. Unknown output has an explicit unavailable state. Selection has
checkmarks and boundaries. Preview, unapplied drafts and applied output remain
distinct. No essential state depends on color perception.

Scenes retain their saved targets. Music separates input, interpretation and
generated output; previews never claim physical device confirmation. Technical
metadata belongs where it helps a decision, with secondary tools in disclosures.

## Voice and hierarchy

Use room, fixture and scene names as ordinary language. Say what an action will
affect. Distinguish Stop & restore from Keep current light. Say “generated” when
output is generated and “not responding” when connectivity is uncertain. State
limitations where they change a decision: browser whole-fixture output, limited
simultaneous zones, held layouts, permissions and failed placement.

Use system typography, sentence case, 12-point minimum token text and tabular
numbers. Monospace is for addresses and diagnostics. Compactness comes from
shared controls and disclosures, not microscopic text.

## Platform behavior

macOS retains windows, menus, shortcuts, undo, native color picker and focused
sheets. A native split-view sidebar names rooms, devices and destinations. iOS keeps native
tabs and navigation. Settings, scheduling and device administration are secondary
to the room workspace. The production browser retains its room workspace within its existing bridge
capabilities; it does not expose native segment editing.

The existing app mark remains unchanged: this redesign changes the operating
application rather than creating an unrelated logo campaign. Its geometric room
mark is compatible with the room-first direction. Token implementation and
exceptions are documented in DESIGN_SYSTEM.md; native implementation details
are in SPECTRUM_STUDIO.md.
